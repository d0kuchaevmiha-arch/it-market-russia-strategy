Задание 7 — Агентная модель: 3 типа + AI-брокер (RL)
Стилизованная мультиагентная симуляция (запущена, код ниже): вендоры обучаются табличным Q-learning, спрос — логит-модель потребителя. Проверяется влияние доли агентов с идентичным алгоритмом на волатильность цен. Регулятор описан концептуально и в симуляции не реализован.

🏢 Агент: Фирма (IT-вендор)

Цель: Максимизировать прибыль π = (p − c) · q

Стратегии:
• Ценообразование на основе ценности (value-based)
• Адаптация к рыночному спросу (price-elastic)
• Минимизация оттока клиентов (churn)

В симуляции:
цена выбирается из 5 уровней (1,2–2,0), обучение — Q-learning (см. ниже); издержки c = 1,0.

⚖️ Агент: Регулятор (концепция, не симулирован)

Цель: Минимизировать системный риск, контролировать HHI < 2500

Стратегии:
• Штрафы за хищническое ценообразование
• Ограничение монопольной доли рынка
• Обязательная сертификация AI-продуктов

Триггер вмешательства:
Если Δp > −30% за квартал → расследование

👤 Агент: Потребитель (B2B)

Цель: Максимизировать полезность U при бюджете B

Стратегии:
• Выбор поставщика по TCO (цена + интеграция)
• Переговоры о долгосрочных контрактах
• Диверсификация вендоров (multi-source)

В симуляции:
логит-спрос: доля_i ∝ exp((a − p_i)/μ), a = 2,0, μ = 0,25; плюс общий для рынка случайный шок спроса (σ = 0,1).

AI-брокер с обучением с подкреплением (Q-learning)

Архитектура агента

  • Состояние S: округлённая средняя цена рынка прошлого шага (5 уровней)
  • Действие A: выбор цены из {1,2; 1,4; 1,6; 1,8; 2,0}
  • Награда R: прибыль за шаг (p − c) · доля
  • Алгоритм: Q(s,a) ← Q(s,a) + α[r + γ·max Q(s',a') − Q(s,a)]

Параметры обучения

  • α (learning rate) = 0,05; γ = 0,95; ε-greedy ε = 0,1
  • 10 вендоров, 60 000 шагов за запуск; волатильность измерена на последних 10 000
  • Конфигурации: 0 / 2 / 4 / 6 / 8 вендоров используют одну общую Q-таблицу (идентичный алгоритм), остальные учатся независимо
  • По 20 независимых запусков на конфигурацию
Результат симуляции: доля идентичных алгоритмов → волатильность средней цены

Код симуляции (Python, воспроизводимо)
"""Стилизованная агентная модель: N вендоров, логит-спрос, табличный Q-learning.
Доля M агентов использует ОДНУ общую Q-таблицу (идентичный алгоритм, общие данные),
остальные учатся независимо. Исследуем волатильность средней цены."""
import numpy as np, json, sys

N = 10
PRICES = np.array([1.2, 1.4, 1.6, 1.8, 2.0])
K = len(PRICES)
C = 1.0; A = 2.0; A0 = 0.0; MU = 0.25
ALPHA, GAMMA, EPS = 0.05, 0.95, 0.10
T_TOTAL, T_MEASURE = 60000, 10000
SHOCK = 0.10  # std экзогенного шока спроса (общий для рынка)


def profits(p, shock):
    u = np.exp((A + shock - p) / MU)
    share = u / (u.sum() + np.exp(A0 / MU))
    return (p - C) * share


def run(n_shared, seed):
    rng = np.random.default_rng(seed)
    # индекс Q-таблицы для каждого агента: общий (0) для первых n_shared, свой для остальных
    table_id = np.array([0] * n_shared + list(range(1, N - n_shared + 1)))
    Q = np.zeros((N - n_shared + 1, K, K))  # [таблица, состояние, действие]
    state = 2
    mean_prices = []
    for t in range(T_TOTAL):
        qrows = Q[table_id, state]                       # (N, K)
        greedy = qrows.argmax(axis=1)
        explore = rng.random(N) < EPS
        a = np.where(explore, rng.integers(0, K, N), greedy)
        p = PRICES[a]
        r = profits(p, rng.normal(0, SHOCK))
        ns = int(np.clip(np.rint((p.mean() - PRICES[0]) / 0.2), 0, K - 1))
        for i in range(N):
            tid = table_id[i]
            td = r[i] + GAMMA * Q[tid, ns].max() - Q[tid, state, a[i]]
            Q[tid, state, a[i]] += ALPHA * td
        state = ns
        mean_prices.append(p.mean())
    mp = np.array(mean_prices[-T_MEASURE:])
    return mp.std(), np.abs(np.diff(mp)).mean(), mp.mean()


if __name__ == "__main__":
    SEEDS = int(sys.argv[1]) if len(sys.argv) > 1 else 12
    out = {}
    for n_shared in [0, 2, 4, 6, 8]:
        res = np.array([run(n_shared, s) for s in range(SEEDS)])
        out[n_shared] = {
            "std_mean": res[:, 0].mean(), "std_sd": res[:, 0].std(ddof=1),
            "absdiff_mean": res[:, 1].mean(), "price_mean": res[:, 2].mean(),
            "std_all": res[:, 0].tolist(),
        }
        print(n_shared, out[n_shared]["std_mean"], out[n_shared]["std_sd"], flush=True)
    json.dump(out, open("/tmp/abm_results.json", "w"), indent=1)

  • Равновесия: (S2, C1) и (S2, C3) — слабые, так как против S2 конкурент безразличен. (S3, C2) равновесием не является: против S3 конкурент предпочёл бы C1 или C3.
  • S1 строго доминируется S2 в каждом столбце (−4 < 6, 5 < 7, 7 < 8).
  • При p(C1) = 0,6, p(C2) = 0,4: ожидаемый выигрыш S2 = 6,4; S3 = 5,6; S1 = −0,4. Лучший ответ — чистая S2.
  • Смешивать S2 и S3 имеет смысл только при p(C1) = 1/3 (и p(C3) = 0): там обе дают 6,67.

Стратегия защиты от хищнического ценообразования

  • Шаг 1: Дифференциация — уникальные функции и интеграции с ERP/CRM клиента (S2 — равновесная стратегия; заодно растут switching costs)
  • Шаг 2: 2–3-летние контракты с exit penalty как дополнение (S3 — лучший ответ, если конкурент играет стандартно)
  • Шаг 3: Мониторить ценовые действия конкурентов (парсинг публичных прайсов)
  • Шаг 4: Reputation effect — демонстрировать стабильность цен публично
Вывод: оптимальна чистая стратегия S2 «Дифференциация». Она даёт максимальный гарантированный выигрыш (минимум 6, у S3 — 4) и является лучшим ответом при p(C1) = 0,6. Смешанная стратегия 55% / 45% была бы хуже: против хищнического конкурента она даёт 5,1 вместо 6. Строго говоря, это лучший ответ при заданных вероятностях, а не полное байесовское равновесие: конкурент здесь «чёрный ящик» без заданной функции типов. S1 (ценовая война) строго доминируема и исключается.
