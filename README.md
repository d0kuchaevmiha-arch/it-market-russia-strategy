# Стратегический анализ IT-рынка России (B2B SaaS)

Аналитическая записка: STEEP, 5 сил Портера, анализ чувствительности, Монте-Карло, чёрные лебеди, стилизованная агентная модель и равновесие Нэша.

**Открыть записку:** `index.html` (можно открыть в браузере напрямую).

## Что подтверждено, а что — допущение

- **Подтверждено публичными источниками (выручка 2025 г.):** Группа Астра (>20 млрд ₽, МСФО), Positive Technologies (30,9 млрд ₽, МСФО), Softline (оборот 132,1 млрд ₽), СКБ Контур (48,3 млрд ₽), объём рынка по CNews500 (3,56 трлн ₽). Ссылки — во вкладке «Источники и допущения».
- **Допущения автора (не данные):** веса и вероятности в STEEP, баллы сил Портера, NPV/IRR по группам, параметры Монте-Карло, вероятности «чёрных лебедей», платёжная матрица в задании Нэша.
- **Не проверено:** выручка 1С, Kaspersky, КРОК, IBS, Naumen, Dr.Web, Базальт СПО — эти компании исключены из групп.

## Агентная модель (`abm_sim.py`)

Стилизованная симуляция: 10 фирм с табличным Q-learning, логит-спрос, общий шок спроса.
Проверяется, как доля фирм с одинаковым алгоритмом (общая Q-таблица) влияет на волатильность средней цены.

```
python3 abm_sim.py 20
```

Результат: при 40% одинаковых алгоритмов волатильность немного ниже базовой; заметный рост — при 60% и выше.
Гипотеза «+52–68% при 40%» не подтвердилась. Регулятор не моделировался, чувствительность к параметрам не исследовалась.
